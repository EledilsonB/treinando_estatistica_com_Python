## Repositório para treinamento em Estatística
Criei esse repositório para treinar algumas fórmulas estatísticas, junto com bibliotecas de análise e visualização, como: Seaborn, Pandas, NumPy, MatPlotLib e por ai vai... 

### Até agora comecei com conceitos básicos, como:
- Calculos de Média, moda, mediana.
- Calculos de desvio padrão e variância
- Teste de visualização amostral
- Médias Populacional e Amostral
- Quartis e Amplitude
